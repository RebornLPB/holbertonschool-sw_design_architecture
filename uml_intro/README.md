# Software Design - Introduction to UML

## Description
This project introduces the **Unified Modeling Language (UML)** through two diagram types written in [Mermaid](https://mermaid.js.org/) syntax: a class diagram modeling a small library system, and a sequence diagram.

## 📝 Learning Objectives
* Model classes, their attributes/methods, and relationships (associations, multiplicities) in a UML class diagram.
* Model the interaction between objects over time in a UML sequence diagram.
* Write and render diagrams using Mermaid's text-based syntax.

## 🛠️ Requirements & Engineering Constraints
* **Format:** Diagrams are written as `.mmd` files using Mermaid syntax.
* **Rendering:** Viewable with the [Mermaid Live Editor](https://mermaid.live/) or any Markdown renderer with Mermaid support.

## 📁 File List & Tasks Directory

| File | Task Title | Description |
| :--- | :--- | :--- |
| `0-class_diagram.mmd` | Class Diagram | Models a small library system: `Book`, `User`, `Loan`, and `Library`, with their attributes, methods, and association multiplicities. |
| `1-sequence_diagram.mmd` | Sequence Diagram | ⚠️ Not started yet — currently contains a placeholder note instead of a diagram. |

---

## 🚀 Viewing the Diagrams

Paste the content of a `.mmd` file into the [Mermaid Live Editor](https://mermaid.live/) to render it, or preview it directly in an editor with Mermaid support (e.g. VS Code with a Mermaid extension).
