# Holberton School - Software Design & Architecture

## 📖 About
This repository gathers the projects completed during the **Software Design & Architecture** track at **Holberton School**: modeling systems with UML diagrams and implementing classic Gang-of-Four design patterns in Python.

---

## 🛠️ General Requirements & Environment
* **OS:** Ubuntu 20.04 LTS
* **Interpreter:** `python3` (version 3.8.5+)
* **Style Guide:** All Python source files are meant to follow **PEP 8**.
* **Diagrams:** UML diagrams are written in [Mermaid](https://mermaid.js.org/) syntax (`.mmd`).

---

## 📚 Project Overview

| Directory | Core Concepts / Highlights |
| :--- | :--- |
| [`uml_intro`](uml_intro/) | Class diagrams and sequence diagrams (Mermaid) |
| [`design_patterns`](design_patterns/) | Factory, Observer, and Decorator patterns |

---

## 🚀 Quick Start

```bash
git clone https://github.com/RebornLPB/holbertonschool-sw_design_architecture.git
cd holbertonschool-sw_design_architecture/design_patterns
python3 0-factory.py
```
